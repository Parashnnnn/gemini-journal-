## 🧠 About

**Gemini Journal** is an AI-powered journaling application designed to make personal reflection more meaningful, organized, and intelligent.

Write your thoughts, experiences, ideas, and daily reflections in a simple journal interface while leveraging AI to help you better understand and interact with your entries.

🌐 **Live App:** https://gemini-journal-one.vercel.app/

---

## ✨ Features

* 📝 **Personal Journaling** — Write and organize your thoughts in one place.
* 🤖 **AI-Powered Experience** — Use Gemini-powered intelligence to enhance your journaling experience.
* 💭 **Reflection & Insights** — Turn your journal entries into meaningful reflections.
* 🎨 **Clean & Modern Interface** — Minimal, focused design built for a distraction-free experience.
* ⚡ **Fast & Responsive** — Optimized for a smooth experience across devices.

## 🚀 Getting Started

Follow the steps below to run Gemini Journal locally.

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd <your-repository-folder>
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure your Gemini API key

Create a `.env.local` file in the root directory:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Replace `your_gemini_api_key` with your Google Gemini API key.

> ⚠️ **Security:** Never commit your `.env.local` file or expose your API key publicly.

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal, typically:

```text
http://localhost:5173
```

## 🌐 Deployment

Gemini Journal can be deployed easily using **Vercel**.

1. Push your project to GitHub.
2. Import the repository into Vercel.
3. Add your `GEMINI_API_KEY` as an environment variable.
4. Deploy the project.

Once deployed, your application will be available through your Vercel domain.
